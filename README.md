## Hi Ana Cristina

Este projeto representa minha transição da área acadêmica para o contexto corporativo, unindo minha experiência em educação, psicologia e gestão de pessoas.

Aqui apresento uma proposta de educação corporativa focada no desenvolvimento de lideranças, aprendizagem contínua e engajamento.

Acredito no desenvolvimento humano como estratégia essencial para o crescimento das organizações, e este projeto reflete minha forma de pensar, estruturar e aplicar soluções de aprendizagem.
